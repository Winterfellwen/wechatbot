# AI运势功能重构设计文档

## 概述

重构现有AI运势功能，从"选择类型→输入信息→单次测算"改为"档案驱动→分类测算→流式输出→多轮对话"的全新体验。

### 核心变更

| 项目 | 原设计 | 新设计 |
|------|--------|--------|
| 分类命名 | 中国运势/西方运势 | 易学命理/西方星象 |
| 用户信息 | 每次输入 | 预先建立档案 |
| 测算方式 | 单次单类型 | 一次测算3个类型 |
| 输出方式 | 等待完整结果 | SSE流式逐token输出 |
| 交互方式 | 查看结果即结束 | 支持AI多轮追问 |
| 页面数量 | 6个 | 4个（精简） |

---

## 一、整体架构

### 页面结构

| 页面 | 路径 | 功能 |
|------|------|------|
| 首页 | `pages/index/index` | 档案表单 + 分类入口（易学命理/西方星象） |
| 测算页 | `pages/reading/reading` | 3个运势卡片逐张流式输出 + 浮动AI对话按钮 |
| 对话页 | `pages/chat/chat` | 多轮追问（基于测算结果），支持对话记录保存 |
| 历史页 | `pages/history/history` | 历史记录列表，点击查看完整结果 |

### 导航流程

```
首页（填写档案）→ 测算页（流式输出3个运势）
                 → 浮动按钮 → 对话页（多轮追问）
                 → 历史页 → 查看历史测算结果
```

### 删除的页面

- `pages/types/` — 不再需要，分类直接在首页选择
- `pages/input/` — 不再需要，档案预先建立
- `pages/daily/` — 不再需要，功能合并到测算页
- `pages/result/` — 不再需要，结果直接在测算页展示

## 二、数据模型

### 用户档案

**Storage Key:** `fortune_profile`

```json
{
  "name": "张三",
  "birthday": "1990-05-15",
  "gender": "male",
  "birthTime": "子时"
}
```

**字段说明：**
- `name` — 用户姓名
- `birthday` — 生日，格式 YYYY-MM-DD
- `gender` — 性别：male / female
- `birthTime` — 出生时辰（选填），可选值：子时、丑时、寅时、卯时、辰时、巳时、午时、未时、申时、酉时、戌时、亥时

## 四、流式输出实现

### NVIDIA API SSE流式请求

**请求参数：**
```javascript
{
  model: "nvidia/nemotron-3-nano-omni-30b-a3b-reasoning",
  messages: [
    { role: "system", content: "你是一个专业的运势分析师..." },
    { role: "user", content: "请分析以下用户的八字命理..." }
  ],
  stream: true,
  max_tokens: 2000
}
```

**响应格式（逐token返回）：**
```
data: {"choices":[{"delta":{"content":"您"}}]}
data: {"choices":[{"delta":{"content":"的"}}]}
data: {"choices":[{"delta":{"content":"八字"}}]}
...
data: [DONE]
```

### 小程序端实现

**技术方案：**
- 使用 `wx.request` + `enableChunked: true`
- 监听 `onChunkReceived` 事件，逐块解析SSE数据
- 每收到一个token，更新对应卡片的内容

**关键代码逻辑：**
```javascript
// 伪代码
const requestTask = wx.request({
  url: 'https://integrate.api.nvidia.com/v1/chat/completions',
  method: 'POST',
  enableChunked: true,
  header: { 'Authorization': 'Bearer ' + apiKey },
  data: { ...params, stream: true }
});

requestTask.onChunkReceived(function(res) {
  // 解析SSE数据
  // 提取content字段
  // 更新卡片内容
});
```

### 测算流程

1. 用户点击"易学命理"或"西方星象"
2. 第一张卡片状态变为 `loading`，显示"正在分析八字命理..."
3. 调用AI API（stream: true），卡片状态变为 `streaming`
4. 内容逐字显示在卡片中
5. 收到 `[DONE]` 后，卡片状态变为 `completed`
6. 第二张卡片开始，重复步骤2-5
7. 第三张卡片完成后，保存到历史记录
8. 全部完成后，浮动AI对话按钮变为可用状态

## 五、AI对话实现

### 对话上下文构建

**系统提示词模板：**
```
你是一个专业的运势分析师。以下是用户的信息和运势分析结果：

【用户档案】
姓名：{name}
生日：{birthday}
性别：{gender}
出生时辰：{birthTime}

【八字命理分析】
{bazi_result}

【紫微斗数分析】
{ziwei_result}

【易经卦象分析】
{yijing_result}

请基于以上信息回答用户的问题。回答要专业、详细、有深度。
```

### 对话流程

1. 进入对话页，加载对应测算记录的对话历史
2. 如果没有对话历史，显示欢迎消息
3. 用户输入问题，发送到AI API（stream: true）
4. 流式显示AI回复
5. 对话记录保存到本地存储
6. 退出对话页时，对话记录已保存

## 六、错误处理与降级

### 错误场景处理

| 场景 | 处理方式 |
|------|----------|
| 流式输出中断 | 显示已接收内容 + "加载中断，点击重试"按钮 |
| API调用失败 | 重试3次，失败后显示本地生成的运势内容 |
| 档案未填写 | 点击分类时弹出提示"请先填写档案" |
| 出生时辰未填 | 易学命理页面显示提示"未填写时辰，结果可能不准确" |
| 网络断开 | 显示缓存的历史记录，测算功能提示"网络不可用" |

### 本地降级内容

当API失败时，使用预设的模板生成基础运势分析：

- **八字命理**：显示五行分析、十神关系的基础解读
- **紫微斗数**：显示命盘格局、主要星曜的基础解读
- **易经卦象**：显示随机卦象、卦辞的基础解读
- **星座分析**：显示星座特质、今日运势的基础解读
- **塔罗占卜**：显示牌面解读、建议的基础解读
- **占星术**：显示星盘配置、行星相位的基础解读
