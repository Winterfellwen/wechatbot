# 德语学习模块 - 设计方案

## 1. 概述

完全重新开发德语学习模块，包含独立的课程模块和闯关学习模块。采用分包独立模式，所有德语相关文件集中在 german 目录。

## 2. 架构设计

### 2.1 目录结构

```
german/
├── pages/
│   ├── course/         课程模块（静态页面）
│   ├── learn/          闯关模块（动态加载）
│   ├── lesson/         课程详情
│   ├── wordbook/       生词本 + 背单词
│   ├── grammar/        语法讲解
│   ├── textbook/       课文阅读
│   ├── aichat/         老师问答（AI）
│   └── leaderboard/    排行榜
├── data/              德语数据（CEFR分级）
│   ├── a1/             A1等级数据
│   ├── a2/             A2等级数据
│   ├── b1/             B1等级数据
│   └── b2/             B2等级数据
└── utils/              德语专用工具（TTS、算法）
```

### 2.2 模块独立

- 各页面独立，不共享其他功能代码
- 数据层独立管理（german/data/）
- 工具函数独立（german/utils/）

## 3. 闯关模块（核心）

### 3.1 等级结构

| 等级 | 关卡数 | 内容范围 |
|------|--------|----------|
| A1   | 15关   | 基础词汇、基本语法、基础发音 |
| A2   | 15关   | 扩展词汇、复合语法、实用发音 |
| B1   | 15关   | 中级词汇、复杂语法、高级发音 |
| B2   | 15关   | 高级词汇、深入语法、学术发音 |

### 3.2 题型设计

| 题型 | 说明 | 考核能力 |
|------|------|----------|
| 听力题 | 播放德语，选择中文含义 | 听力理解 |
| 选择题 | 4选1，选择正确翻译/语法 | 词汇/语法 |
| 拼写题 | 听写德语单词/短语 | 拼写能力 |
| 排序题 | 将词语重组为正确句子 | 句法结构 |
| 配对题 | 德语词-中文义连线 | 词汇记忆 |

每关包含 5-8 题，从各题型中随机抽取。

### 3.3 错题机制

- **闯关后错题回顾**：闯关结束显示错题列表，点击可立即复习
- **复习关卡**：独立入口，自动筛选最近错题重新组关
- **间隔重复**：错题按艾宾浩斯曲线安排复习（1天→3天→7天→30天）

### 3.4 闯关流程

1. 选择等级 → 选择关卡
2. 进入闯关界面 → 逐题作答
3. 每题即时反馈（正确/错误+解析）
4. 闯关结束 → 错题回顾 → 统计得分
5. 错题自动加入复习队列

## 4. 课程模块

### 4.1 每级内容

| 类型 | 数量 | 说明 |
|------|------|------|
| 单词 | 200词 | 带发音、中文释义、例句 |
| 语法 | 15-20个 | 讲解+例句+练习 |
| 发音 | 10个 | 发音规则+TTS朗读 |
| 课文 | 10篇 | 短文+翻译+生词 |

### 4.2 学习路径

A1 → A2 → B1 → B2（从易到难）

### 4.3 课程详情页

- 单词：列表展示，可发音、可加入生词本
- 语法：讲解页面 + 示例
- 发音：规则展示 + 跟读对比
- 课文：正文 + 翻译 + 生词标注

## 5. 发音功能

### 5.1 实现方案

使用 **TTS语音合成**（wx.getBackgroundAudioManager 或 wx.createInnerAudioContext）

### 5.2 应用场景

- 单词发音
- 句子朗读
- 听力题目
- 发音规则示例

## 6. 生词本 + 背单词

### 6.1 词汇来源

- **自动收录**：闯关错题、课程标记的生词
- **手动收藏**：用户主动添加

### 6.2 背单词模式

- 卡片式复习（显示德语，回忆中文）
- 间隔重复算法（1天后→3天后→7天后→30天）
- 认识/不认识 按钮切换

### 6.3 数据结构

```javascript
{
  word: "单词",
  translation: "中文",
  phonetic: "音标",
  example: "例句",
  level: "A1/A2/B1/B2",
  nextReview: "下次复习时间",
  reviewCount: "复习次数"
}
```

## 7. 老师问答（AI对话）

### 7.1 交互形式

纯文本对话：输入框 + 发送按钮

### 7.2 功能

- 语法答疑
- 翻译帮助
- 学习建议
- 任意德语相关问题

## 8. 排行榜

### 8.1 统计维度

- 总学习天数
- 完成关卡数
- 累计学习单词数
- 连续学习天数

### 8.2 显示

- 个人学习数据概览
- 排名列表（可选显示好友/全局）

## 9. 数据存储

使用微信小程序本地存储：

- 用户进度：wx.setStorageSync
- 生词本数据：wx.setStorageSync
- 学习统计：wx.setStorageSync
- 错题记录：wx.setStorageSync

## 10. 技术要点

- 页面跳转使用 wx.navigateTo
- 数据动态加载，减少包体积
- TTS 调用需要网络支持
- 所有数据本地化，不依赖后端
